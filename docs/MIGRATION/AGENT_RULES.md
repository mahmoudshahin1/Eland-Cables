# Agent Rules (قواعد ملزمة للمساعد الذكي)

## 1. بوابة المراجعة الخارجية (Review Gate)
في نهاية كل Phase يجب أن تنتج ملفًا واحدًا: `docs/MIGRATION/REVIEW_PHASE_<N>.md`
لا يجوز لك البدء في `Phase <N+1>` قبل أن يرسل المستخدم حرفيًا: "تمت المراجعة، ابدأ Phase <N+1>".

محتوى الملف (إلزامي، ومخرجات الأوامر حرفية وليست ملخصات):
1) ملخص: ما تم، وما لم يتم، وأي انحراف عن الخطة.
2) جدول Endpoints: لكل endpoint: method، path، الصلاحية المطلوبة، الـ controller، حالة parity (متطابق/مختلف).
3) مصفوفة الصلاحيات (route → permission → roles المسموح لها) مع مقارنة بالقديم، وأي اختلاف مبرّر.
4) تقرير الـ Parity كاملًا: لكل endpoint النتيجة، وأي diff حرفيًا، وطريقة التشغيل (القاعدتان، الـ seed، الـ fixtures).
5) نتيجة الاختبارات: الأمر المستخدم، العدد (ناجح/فاشل/متخطّى)، والمخرجات.
6) مخرجات build و lint حرفيًا.
7) جدول شاشات React القديمة التي اختُبرت وما نتيجة كل واحدة.
8) قائمة الاختلافات المقصودة عن القديم، وقائمة المشاكل المفتوحة والقرارات المطلوبة.
9) قائمة الملفات التي تغيرت (`git diff --stat`) ومعها أي تعديل على الـ Legacy.
10) فحص أمني ذاتي: لا secrets، لا mock، لا demo users خارج seed المحلي، كل route محمي، لا any. أثبت كل بند بأمر `grep` ومخرجاته.
11) أي حزمة جديدة تم تثبيتها (الاسم والإصدار والسبب).

بعد كتابة الملف: اعرض لي مساره وطوله، وقل لي "جاهز للمراجعة"، ثم توقف تمامًا.
