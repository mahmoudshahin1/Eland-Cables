## 1. تعليمات إجراء الاختبار اليدوي (How to Test A/B)

لإجراء اختبار القبول اليدوي والتأكد من مطابقة السلوك بين النظام القديم والجديد جنباً إلى جنب:
1. **الطرف أ (Legacy Express):** يعمل على المنفذ `http://127.0.0.1:3847`.
2. **الطرف ب (NestJS + React UI via Proxy):** افتح المتصفح على `http://localhost:5173`.
3. افتح نافذتين متجاورتين، ونفّذ نفس الخطوات وسجّل النتيجة في عمود **"نتيجة المستخدم"** أدناه (`✅ ناجح` أو `❌ اختلاف` مع إرفاق لقطة شاشة عند الاختلاف).

|---|---|:---:|---|---|---|:---:|

| **UAT-2A-02** | حاسبة البراميل للعميل (`/customer/drum-optimizer`) | المسار السعيد (Happy Path) | 1. سجّل الدخول كعميل.<br>2. ادخل قطر الكابل: `25mm`، والوزن: `1200kg/km`.<br>3. اختر طول تقطيع: `1000m` واضغط Calculate. | تظهر قائمة البراميل المناسبة مع نسب الامتلاء ونوع البرميل الموصى به بدون أي أخطاء. | قارن ترشيحات البراميل ونسبة الامتلاء المحسوبة مع القديم. | |
| **UAT-2A-03** | مركز الماستر داتا الداخلي (`/internal/master-data`) | المسار السعيد (Happy Path) | 1. سجّل الدخول كمدير نظام `admin@energya.com`.<br>2. افتح مركز الماستر داتا.<br>3. راجع تبويبات الكابلات والخامات والـ BOM والبراميل. | ظهور القوائم الكاملة: **432 كابل، 74 خامة، 4,822 سطر BOM، و105 براميل** بدقة تامة. | قارن الأعداد الإجمالية للأسطر وأول 5 عناصر في كل قائمة. | |
| **UAT-2A-04** | مسارات الكابلات بدون مصادقة (`GET /api/master/cables`) | حالة أمنية (Anonymous) | افتح المتصفح أو أداة API واستدعِ المسار مباشرة بدون توكن مصادقة. | يعود الخادم فوراً برمز `401 Unauthorized` ورسالة منع الدخول. | مطابقة كود الحالة `401` ورسالة الخطأ مع الخادم القديم. | |
| **UAT-2A-05** | مستخدم داخلي بلا صلاحيات (`/internal/master-data`) | حالة أمنية (Permissions) | 1. سجّل الدخول بحساب `limited@parity.test` (مستخدم داخلي بلا صلاحيات ماستر داتا).<br>2. حاول فتح الماستر داتا. | حظر الوصول فوراً وعرض شاشة منع الدخول أو رمز `403 Forbidden`. | مطابقة رمز المنع `403` بين القديم والجديد. | |
| **UAT-2A-06** | رفع مرفق بحساب العميل (`POST /attachments`) | حالة أمنية (Client Privilege) | سجّل الدخول كعميل وحاول إرسال طلب إضافة مرفق لكابل عبر المتصفح أو الـ API. | رفض الطلب برمز `403 Forbidden` (العميل للقراءة فقط). | مطابقة رد المنع `403` في الخادمين. | |
| **UAT-2A-07** | رفع وتنزيل مرفق ثنائي 5MB (`Attachments`) | حمولة ثنائية (Binary Payload) | 1. بحساب الأدمن، ارفع ملف PDF بحجم 5MB لكابل.<br>2. اضغط تنزيل المرفق بعد حفظه. | نجاح الرفع برمز `201` وتنزيل الملف بحجمه الكامل (`5,242,880 بايت`) وفتحه بدون أي تلف. | قارن حجم الملف المنزّل وبايتاته مع الملف الأصلي المرفوع. | |
| **UAT-2A-08** | استعلام عن كابل غير موجود (`GET /cables/99999999`) | معالجة الأخطاء (Error Handling) | اطلب كابلاً برقم مادة وهمي غير مسجل في النظام. | يعود الخادم برمز `404 Not Found` ورسالة خطأ واضحة بدون انهيار. | مطابقة رمز `404` وصيغة استجابة الخطأ مع القديم. | |
| **UAT-2A-09** | طول تقطيع مفرط في البراميل (`Drum Optimizer`) | حالة حدّية (Edge Case) | في حاسبة البراميل، أدخل طول تقطيع ضخم غير واقعي (مثلاً `100,000m`) لنفس الكابل. | معالجة الطلب وتنبيه المستخدم بأن الطول يتجاوز أقصى سعة لكافة البراميل المتاحة. | مطابقة سلوك رسالة التحذير بين الواجهتين. | |
